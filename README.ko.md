# 한국 특허명세서 Word/HWP → HLT 변환 프로토타입

`web-converter.html`은 초안 파일을 드롭하면 특허명세서 섹션을 자동 분류해 `.hlt` 파일(프로토타입 XML)로 다운로드하는 단일 페이지 도구입니다.

## 사용 방법
1. 브라우저에서 `web-converter.html` 열기
2. `.docx`, `.hwpx`, `.txt` 파일 드래그 앤 드롭
3. **HLT로 변환** 버튼 클릭
4. 자동 다운로드된 `.hlt` 파일을 서식기 입력 전 검토

## 현재 범위
- 지원: `.docx`, `.hwpx`, `.txt`
- 미지원: 바이너리 `.hwp` (서버측 파서 또는 OCR 연동 필요)
- 섹션 분류: 발명의 명칭/기술분야/배경기술/발명의 내용/도면의 간단한 설명/실시예/청구범위/요약

## 다음 고도화 제안
- 실제 특허청 서식기 HLT 스키마 역공학 후 정확 출력
- `.hwp` 업로드 서버 변환 파이프라인 추가
- 청구항 번호 인식 및 도면부호 정규화
- 개인정보/기술정보 보안을 위한 온프레미스 배포
