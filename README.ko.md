# 한국 특허명세서 Word/HWP → HLT 변환 웹페이지

`web-converter.html`은 웹페이지에서 파일을 드래그 앤 드롭하면 즉시 변환을 시작해 `.hlt` 파일(프로토타입 XML)로 다운로드하는 단일 페이지 도구입니다.

## 사용 방법
1. 브라우저에서 `web-converter.html` 열기
2. `.docx`, `.hwpx`, `.txt`, `.hwp` 파일 드래그 앤 드롭 또는 파일 선택
3. 파일을 놓는 즉시 변환 시작 (필요하면 **수동으로 다시 변환** 버튼 사용)
4. 자동 다운로드된 `.hlt` 파일을 서식기 입력 전 검토

## 현재 범위
- 지원 변환: `.docx`, `.hwpx`, `.txt`
- `.hwp` 업로드: 가능하지만 브라우저 단독 변환은 불가(오류 메시지로 안내)
- 섹션 분류: 발명의 명칭/기술분야/배경기술/발명의 내용/도면의 간단한 설명/실시예/청구범위/요약

## 다음 고도화 제안
- 실제 특허청 서식기 HLT 스키마 역공학 후 정확 출력
- `.hwp` 서버 변환 파이프라인(파서/OCR) 추가
- 청구항 번호 인식 및 도면부호 정규화
- 개인정보/기술정보 보안을 위한 온프레미스 배포
